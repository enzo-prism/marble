Marble 2.5 (79) replaces the previously approved 2.5 (77) candidate. Please review build 79. This candidate includes the workout-history/draft/storage improvements and adds 25 short athlete quotes (131 bundled quotes total), with one-line filtering in both quote views.

No account or sign-in is required. There are no review credentials. Core workout, planning, supplement, trend, bodyweight, and backup data is stored locally. No ads, third-party tracking, or Marble-operated server. JSON backups exclude actual progress photos and videos, which remain on the device.

Apple Health is optional and permission-based. The app can read workouts/body measurements and optionally write completed strength sessions. Apple Watch and Garmin workouts arrive through Apple Health; there is no Marble Watch app. Strava is not configured and its UI is hidden. Marble supports iPhone and iPad on iOS/iPadOS 26.0 or later.

REVIEW PATH
1. Open Add (the default tab). Paste:
Push day
Bench Press 3x8 @ 185 lb
Tap Review Workout, inspect the structured sets, and edit a value or note. Parsing stays on-device; Apple Intelligence is used when available, with a deterministic notation parser/fallback.
2. Before saving, leave and relaunch. Choose Resume Workout, verify the edits, then save once. Resume itself does not insert a workout. Discard Draft is the separate action for starting over.
3. Open Log > Workout History. The Workout Sessions screen lists the saved session. Search by Bench Press or filter by date. Open the session and choose Repeat Workout. Inspect/edit, then save or cancel. Opening Repeat alone does not save a workout. Finished workouts and pasted/scanned sessions appear here; individual sets and Health imports remain in Log.
4. Open Progress. The overview shows Top Exercises (up to five exercises with a recorded weight best and date) plus the quote footer. Tap a quote to advance; swipe left/right to browse. Open Details for charts and Daily Highlights. Daily Highlights appears only within its configured daily window; change this in Settings > Daily Highlights if needed. It is not a missing feature outside that window.
5. Quotes are attributed text, not athlete endorsements. The full catalog has 131 entries, but each layout filters out quotes that cannot fit one line at the current text size, including Bold Text. The Daily Highlights counter shows only its eligible pool; the overview omits a visible counter. If no quote fits, the decorative quote view is empty.
6. Open Add > Settings > Data & Backups to export a JSON backup through Files or inspect restoration. Use disposable test data for restore checks. Photos/videos are excluded from the JSON backup.
7. Optionally start a workout from Add > Plan, log sets through the active workout accessory, and finish it. The session then appears in Workout History. Health permissions, widgets, and system shortcuts are optional to core review.

STORAGE RECOVERY
The Unable to open workouts screen appears only if persistent storage cannot open. Try Again retries the original store. Prepare Recovery Copy, then Save Recovery Copy, lets the user save private training files with the system share interface. Nothing is automatically uploaded. A recovery copy does not repair or replace the database. Logging remains paused rather than writing workouts to temporary storage. Do not uninstall to bypass a storage failure; uninstalling can remove local data. Normal backup restoration is in Settings after the database is available.
