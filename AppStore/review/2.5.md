# Marble 2.5 review notes

Marble does not require an account or sign-in. Core workout, supplement, planning,
trend, bodyweight, and backup data is stored locally. The app has no ads,
third-party tracking, or Marble-operated server. No credentials are required for
review. JSON backups contain persisted training data; actual progress photos and
videos remain on the device and are excluded from those backups.

Apple Health access is optional and requires permission. Marble can read workouts
and body measurements and optionally write completed strength sessions. Apple
Watch and Garmin workouts enter through Apple Health. Strava is not configured
for this release and its UI stays hidden.

## What is new

- **Workout History** in Log opens **Workout Sessions**: search by workout or
  exercise, filter by date, inspect a completed session, and repeat it as an
  editable review draft. This list includes finished workouts and pasted/scanned
  sessions. Individual sets and Health/Strava imported summaries remain in Log;
  it is not a combined history of every import source.
- Interrupted Add reviews retain edited sets, notes, dates and exercise matches.
  Resume restores the draft for review and does not itself insert a workout.
- If the local workout database cannot open, the app pauses logging and offers
  retry and recovery-copy controls while preserving original workout files.
- Backup restoration and history loading improvements. No account or server is
  introduced, and the deployment target remains iOS 26.0.

## Suggested review path

1. Open **Add**, the default tab. Paste `Push day` followed by
   `Bench Press 3x8 @ 185 lb`. Tap **Review Workout**, inspect the parsed sets,
   and edit a value or note. Parsing stays on-device; Apple Intelligence is used
   when available with a deterministic notation parser and fallback.
2. Before saving, leave and relaunch the app. In Add, choose **Resume Workout**
   when the saved-draft screen appears. Verify your edits, then save once.
   **Discard Draft** is the separate destructive action for starting over.
3. Open **Log > Workout History**. The **Workout Sessions** screen lists the
   saved session. Search for Bench Press or filter by date. Open the session and
   choose **Repeat Workout**. Inspect/edit the new review draft, then save or
   cancel; opening Repeat alone does not create a saved workout.
4. In **Log**, use **+** to log an individual set. Switch between Sets, Calendar
   and Supplements using the Log mode control. Individual sets remain separate
   from the session list described above.
5. Open **Progress** for the weekly overview, then **Details** for charts,
   records, reports, body measurements and other detailed progress views.
6. Open **Add > Settings > Data & Backups** to export a JSON backup through
   Files and inspect the restore flow. Use a disposable test dataset for restore
   checks; actual progress photos/videos are excluded from JSON backup files.
7. Optionally start a workout from **Add > Plan**, log sets through the active
   workout accessory, and finish it. The finished session appears in Workout
   History. Health permissions and system widgets are optional to core review.

## Storage recovery behavior

The **Unable to open workouts** screen appears only if persistent storage cannot
open; it is not a normal onboarding step. **Try Again** retries opening the
original store. **Prepare Recovery Copy**, followed by **Save Recovery Copy**,
lets the user save a copy through the system share interface. A recovery copy
contains private training data and is not automatically uploaded or sent to
support. Preparing it does not repair or replace the database. The app does not
accept new workouts into temporary storage while this screen is shown.

Do not uninstall an existing installation to work around a storage failure;
that can remove its local data. Normal backup restoration is in Settings after
the database is available, not a repair button on this failure screen.

## Device scope and evidence

Marble supports iPhone and iPad; there is no Marble Apple Watch app. Apple Watch
workouts are imported through Health on the paired iPhone. The screenshot dataset
contains deterministic sample training data.

These notes describe the candidate and review route, not completed device
acceptance. Exact-source automated evidence and physical-device signoff are
tracked separately in `AppStore/PHYSICAL_DEVICE_CHECKLIST_2.5.md`. Accessibility
Nutrition Labels require their own verified evidence and publication workflow;
these notes make no new declaration of passed hardware accessibility testing.
