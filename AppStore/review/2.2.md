# Marble 2.2 review notes

Marble does not require an account or sign-in. All core workout, supplement,
planning, trend, bodyweight, and backup data is stored locally. The app has no
ads, third-party tracking, or Marble-operated server.

Apple Health access is optional. Marble reads workouts and body measurements
only after permission is granted, and can optionally write completed strength
sessions to Apple Health. Garmin workouts enter through Apple Health. Strava is
not configured in this build and its UI remains hidden. No credentials are
required for review.

## What is new

- Weekly Goal widgets for Home Screen and Lock Screen, with a medium-widget
  quick-log button.
- Interactive rest Live Activity controls, rest-complete notification, and
  Control Center quick log.
- Siri, Shortcuts, and Spotlight support for exercises, sets, and workout
  sessions.
- Daily Highlights, a local-only end-of-day progress recap.
- Manual and Apple Health bodyweight tracking, bodyweight trends, and per-lift
  DOTS relative-strength scores.
- Onboarding and centralized Settings.
- Expanded JSON backup and restore for all persisted entity types. Photo and
  video binaries remain on-device and are intentionally excluded.

## Suggested review path

1. Open **Journal**, tap **+**, choose an exercise, and log a set. The logging
   screen shows the last set and personal-record target.
2. Open **Workout**, start a workout, add or repeat a set, then finish it.
3. Open **Trends** to review Weekly Goal, strength coaching, Daily Highlights,
   and bodyweight. Daily Highlights appears from 8:00 PM through 11:59 PM by
   default and can be customized in Settings.
4. Open **Workout > Settings** to review units, weekly goal, reminders, Apple
   Health options, privacy information, and **Data & Backups**.
5. Add Marble's **Weekly Goal** widget. The medium Home Screen widget includes
   a **Log set** button; the Lock Screen supports circular, rectangular, and
   inline families.
6. Log a set with rest enabled to start the Live Activity. Its **+30s** and
   **End** controls work from the Lock Screen and Dynamic Island.
7. Add Marble's **Log a Set** control in Control Center, or run the Siri phrase
   “Log a set in Marble.”

The screenshot dataset is deterministic and contains sample training data only.
