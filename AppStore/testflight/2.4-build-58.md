# Marble 2.4 (58) TestFlight plan

## What to Test (en-US)

Marble 2.4 build 58 is the release candidate for bulk workout import and the
final logging-accessibility pass. Please import a real Hevy or Strong CSV or a
multi-day Notes workout, review every exercise and set, and confirm there is no
silent loss. Also check Train / Log / Progress navigation, the Sets / Calendar /
Supplements picker at large text sizes, Add Set with VoiceOver and larger text,
and keyboard dismissal in Paste or Type. Send feedback with the source format
and smallest sample that reproduces any mismatch.

## Focused acceptance pass

- Hevy: warmups, failure rows, RPE, notes, session timing, and repeated exercise
  blocks.
- Strong: semicolon-delimited exports, decimal commas, kg, distance, equipment
  suffixes, and `superset_id` notes.
- Notes: `Day` / `Session` boundaries, `RPE 8` / `@RPE 8`, multiple workouts,
  weak matches, and new-exercise creation.
- Scan: multi-page order, exercise reordering, visible rest/RPE/notes, and
  re-scan deduplication.
- Accessibility: Log mode controls and Add Set remain readable, reachable, and
  correctly disabled at accessibility text sizes in light and dark appearance.
- Regression: planned-set completion, sprint timing, editable weigh-ins, backup
  export, restore preview, and the shipped-2.3 data migration.

## Exit criteria

- The processed build is tied to the exact merged GitHub SHA and is `VALID`.
- At least 48 hours installed by more than the owner account.
- At least one complete Hevy, Strong, Notes, and scan pass with no silent loss.
- No launch, save, migration, restore, accessibility, or keyboard regression.
- The physical-device checklist is signed for both iPhone and iPad.
- Any mismatch is fixed or documented accurately before public review.
