# Marble 2.4 (59) TestFlight plan

Application feature source: `c8200e219b47e44d26720d164cd568f395392f6f`

Exact uploaded `main` SHA: `BUILD_59_SOURCE_SHA`

App Store Connect build ID: `BUILD_59_ID`

## What to Test (en-US)

Marble 2.4 build 59 makes Add the default, AI-first way to log a workout.
Paste or type natural language, gym notation, multi-day Notes, or a Hevy/Strong
CSV, then verify that Marble creates the right workouts, exercises, sets, dates,
units, rest, RPE, and notes before anything is saved. Apple Intelligence handles
prose on supported devices; notation and file imports have an on-device
deterministic fallback. Also test draft recovery, Shortcut text handoff,
unresolved-line retry, duplicate exercise names, the active-workout accessory,
VoiceOver, and maximum Larger Text. Send feedback with the smallest source text
or file that reproduces any mismatch.

## Focused acceptance pass

- Default Add: the editor is immediately reachable, including at maximum Larger
  Text; Paste, Choose File, examples, Review Workout, Plan, and Settings work.
- Parsing: natural-language prose, `3x8 @ 185 lb`, timed/bodyweight movements,
  multi-day Notes, Hevy CSV, Strong CSV, European delimiters, and decimal commas.
- Review fidelity: exercise order and exact library identity remain stable;
  similarly named duplicate exercises are not silently merged; create-new stays
  explicit; unresolved rows can be retried independently.
- Persistence: unfinished source text survives tab changes and relaunch; saving
  clears it only after the structured workout is committed.
- Handoff: Shortcut text offers append/replace/keep behavior without losing the
  current draft.
- Active session: the accessory opens the current workout as a secondary sheet;
  nested Add Set works; rest-timer priority remains unchanged.
- Accessibility: VoiceOver names and actions, contrast, hit targets, keyboard
  dismissal, and Accessibility XXXL layouts in light and dark appearance.
- Regression: Log modes, Progress, planned-set completion, sprint timing,
  editable weigh-ins, widgets, backup/restore, and shipped-2.3 migration.

## Exit criteria

- The processed build is tied to the exact merged GitHub SHA and is `VALID`.
- Internal `test group A` receives it automatically through all-build access.
- No launch, save, migration, restore, parsing, accessibility, or keyboard regression.
- At least one complete prose, notation, Hevy, Strong, Notes, and Shortcut pass.
- The physical-device checklist is signed for both iPhone and iPad before public release.
